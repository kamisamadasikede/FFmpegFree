## 产品总览（给新进群同学）

**FFmpegFree（ffc）** 是 Windows / Mac 桌面端（Wails：Go 后端 + 前端），主线在 **`v2` 分支**。能力大致分五块：

| 模块 | 一句话 | 契约落点 |
|------|--------|----------|
| 媒体转换 / 剪辑入口 | FFmpeg 转换、任务中心、格式目录 | §6.9 / §6.14–6.17 |
| 直播推拉流 | 采集、推流、预览（部分仍在推进） | §6.10 |
| 文档转换 / 预览 | Office·WPS 引擎、PDF、办公画布 | §6.12 / GenOffice 方案 |
| 语音转字幕 | ASR 适配器一期（组件可另包） | §6.18 |
| **Cat 助手** | 多 CLI 聚合壳（Grok / Claude / Codex）+ 项目 Git + **项目群聊** | §6.19 / §6.21 |

交付节奏：契约 → 前后端 PR → 合 `v2` → **完整 win64 zip 预览包**（不拆分卷）→ 老板真机验。
