设计规则

三层背景 --bg-app / --bg-panel / --bg-card

底色不再用纯黑，改用带蓝调的灰。层级靠背景差 + 1px 淡描边表达，阴影只留给浮层与弹窗。

单一强调色 --brand #4f8cff

蓝色只用于主操作、选中态和进度。成功/警告/失败三色只出现在状态位，不做装饰。

行骨架统一 缩略图 · 名称 · 元信息 · 状态 · 操作

转换、文档、任务、语音列表都套同一套行结构，用户在一处学会，处处可读。

失败必须可行动 原因 + 重试 + 日志

不再只写「转换失败」。红条给出人话原因，右侧直接给重试与日志入口。

右栏固定宽度 320 / 344 / 356

设置面板统一贴右、吸顶、底部固定主 CTA，主内容区随窗口伸缩。

主题同名 token data-theme="dark|light"

深浅两套只是变量表差异，组件零改动；右上角按钮可直接在原型里切换看效果。
