# ffc 页面重做 · 原型 v1

除 **Agent（Cat）** 外的全部页面重做原型。纯静态 HTML + 一份共享设计系统，**没有改动 `frontend/src` 任何代码**。

## 怎么看（已部署，可直接点）

原型已在本地起了一个零依赖静态服务：

```
http://127.0.0.1:5280/
```

> 服务停了就重新起：`node prototype/serve.mjs 5280`（默认 5280，可换端口）。
> 也可以不开服务直接双击 `prototype/index.html`（`file://` 也能跑，只是地址栏不好分享）。

**能点的东西**

| 交互 | 说明 |
|---|---|
| 左侧栏 | 全部 8 个入口，页间互跳 |
| 顶部页签 | 文档页（文档转换 / PDF 预览）、直播页（文件推流 / 录屏推流 / 拉流播放）可直接切换 |
| 设置子导航 | 通用 / 外观 / 组件管理 会切换右侧分节，关于跳到 11 页 |

## 设计规则（6 条）

1. **三层背景**：`--bg-app`（底）→ `--bg-panel`（侧栏/面板）→ `--bg-card`（内容卡）。层级靠背景差 + 1px 淡描边，阴影只留给浮层。
2. **单一强调色** `--brand #4f8cff`：只用于主操作、选中态、进度；成功/警告/失败三色只出现在状态位。
3. **行骨架统一**：缩略图 → 名称 → 元信息 → 状态 → 操作。转换、文档、任务、语音列表共用一个骨架。
4. **失败必须可行动**：红条给「人话原因」，右侧直接给重试与日志，不再只写「转换失败」。
5. **右栏固定宽度**：320 / 344 / 356 三档，贴右、吸顶、底部固定主 CTA；主内容区随窗口伸缩。
6. **深浅同 token**：`html[data-theme="dark|light"]` 只换变量表，组件零改动（截图里的浅色页即同一份代码）。

## 自适应（11 页全部覆盖）

三档断点，**11 个页面都写了对应的堆叠规则**，不再只有转换页：

| 断点 | 布局变化 |
|---|---|
| ≤1240 | 侧栏 236→212；页边距 24→20；右栏 344→316（直播 356→320、PDF 272→236 等按页）；≤1024 时双栏起收窄 |
| ≤1024 | 侧栏收成 64px 图标轨（只留图标）；顶栏隐藏副标题；**两栏一律收单列**，右栏从「贴右吸顶」改为落到正文下面、整宽、取消吸顶 |
| ≤720 | 侧栏 56px；页边距 12；卡头折行（标题+计数一行，筛选/搜索/按钮第二行）；按钮、内边距、字号收紧；三卡（关于）单列 |

页面级要点：

- **01 转换**：≤1024 单列；≤720 列表行去勾选框、缩略图收小、栏头折行
- **02 语音**：三栏 296+1fr+300 → ≤1024 单列（待转写 / 工作区 / 识别设置纵向排）
- **03 文档转换**：同 01；**04 PDF 预览**：232 缩略图轨 → 阅读区上方横向滑动条，272 文件信息落到最下面
- **05/06 直播推流**：预览 + 356 设置 → 单列；**07 拉流**：播放器 + 320 → 单列
- **08 JSON**：左右两栏 → ≤900 上下两栏（各占一半高），行号栏 46→38
- **09 任务中心**：表格固定列宽，≤1024 允许横向滚动，不把任务名挤没
- **10 设置**：176 竖排子导航 → ≤900 顶部横向胶囊；**11 关于**：三卡 → 两列 → 单列

> 实现侧（`frontend/src`）同步落地了同一套断点，见 `docs/redesign/README.md`「自适应」一节。

```
prototype/
  index.html            总览（页面索引 + 设计规则）
  pages/01..11-*.html   11 个页面
  assets/design.css     设计系统：token + 组件（按钮/卡片/段控/药丸/进度/表格/空态…）
  assets/shell.js       侧栏与顶栏骨架、图标库、主题切换
  assets/nav.js         页间跳转、设置分节切换、右下角悬浮切换器
  serve.mjs             零依赖静态服务（node prototype/serve.mjs 5280）

  shots/                截图（00-overview.png 拼图 / 00-nav.png 切换器展开态）
```

## 落到项目里怎么改（后续工作量参考）

| 层 | 现状 | 落到 frontend/src 的动作 |
|---|---|---|
| 变量 | `styles/tokens.css` 已有 `--ff-*` 两套 | 把本原型的 `--bg-* / --fg-* / --brand / --r-* / --sp-*` 映射过去，保留 `--ff-` 命名避免大改 |
| 组件 | Element Plus + 各页自带 CSS | `styles/element-override.css` 按本原型的按钮/输入/表格规范重写一次 |
| 骨架 | `layout/AppSidebar.vue` + `AppTitlebar.vue` | 侧栏加分组与引擎状态块；顶栏标题/副标题/动作位对齐原型 |
| 单页 | `views/*.vue` | 逐页替换模板结构，先换行骨架与右栏，再调细节 |
| 校验 | `npm run check:*`、`vue-tsc` | 每页改完跑一次类型检查与文案自检 |

> 注意：本原型里的数据是写死的示例（`launch-4k.mov`、`合同-终稿.docx` 等），落地时要把这些位置换成 store 里的真实字段；列宽和状态文案以现有 `api/*.ts` 里的类型为准。
